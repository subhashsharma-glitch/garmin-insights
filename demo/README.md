# Sample dataset — SYNTHETIC (not real user data)

**Status:** the Garmin connector (`user-garmin`) failed on 2026-10-10: "Saved Garmin session is invalid and no credentials are set" (some calls also timed out; HRV/VO2 returned all-null). So **no real data was used**. These files are generated by `generate_synthetic.py` (seed 42) to look like ~90 days of a recreational runner, with a recovery dip planted in the last 7 days to test the rules. Re-run with real data once Garmin is re-authenticated (`garmin-mcp login`).

Anonymisation (for when real data is used): relative day numbers only (day 1 = first day), no names, emails, GPS, device serials, activity IDs or locations; activities numbered 1..n.

## daily.csv (one row per day)
| field | meaning |
|---|---|
| day | relative day 1–90 |
| resting_hr | resting heart rate, bpm |
| hrv_last_night_ms | overnight HRV average, ms |
| sleep_hours | total sleep, hours |
| sleep_score | Garmin-style sleep score 0–100 |
| sleep_midpoint_min_after_midnight | sleep midpoint, minutes after 00:00 |
| bb_max / bb_min | Body Battery daily high / low (5–100) |
| bb_charged / bb_drained | Body Battery points gained / used |
| steps | daily steps |
| acute_load | 7-day sum of synthetic training load |
| chronic_load | 28-day load expressed per week (blank before day 28) |
| load_ratio | acute / chronic (blank before day 28) |

## activities.csv (one row per activity)
| field | meaning |
|---|---|
| activity | sequence number |
| day | relative day |
| type | sport |
| duration_min, distance_km | duration and distance |
| avg_hr | average HR, bpm |
| avg_cadence_spm | steps per minute |
| elevation_gain_m | total climb |
| temperature_c | air temperature |
| decoupling_pct | Pa:HR decoupling on long runs (blank otherwise) |

No VO2 max field is included, to exercise the "not enough data" path.
